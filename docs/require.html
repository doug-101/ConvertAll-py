System Requirements

Linux

Use Python 3.11–3.14 and a dedicated environment installed from requirements-qt6.txt: PyQt6 6.11.0, Qt 6.11.2 and SIP 13.13.0. Normal Qt6 system libraries (GL/EGL, xkbcommon, dbus, fonts and XCB) are required, even for offscreen tests. CI targets Ubuntu 24.04 x86-64.

Windows

Qt6 requires Windows 10 version 1809 or later, or Windows 11 (64-bit). XP, Vista, Windows 7 and Windows 8 are not supported. Native bundle CI targets Windows Server 2022 x64; actual desktop and Inno Setup acceptance remain manual.
